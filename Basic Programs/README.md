# Basic Programs in C

Welcome to **Basic Programs in C**, the starting point of this repository for learning the fundamentals of C programming.

This section contains beginner-friendly C programs designed to build a strong foundation in programming. Each program focuses on a specific concept and helps students understand how to write, compile, execute, and analyze C code.

## Objectives

By completing this section, students will be able to:

- Understand the basic structure of a C program.
- Write, compile, and execute simple C programs.
- Use variables, constants, and fundamental data types.
- Take input from users and display output.
- Perform arithmetic calculations using operators.
- Apply basic type conversion where necessary.
- Develop logical thinking through small programming problems.
- Identify and correct common syntax and compilation errors.

## Topics Covered

### 1. Introduction to C Programming
- Structure of a C program
- Header files and the `main()` function
- Statements, braces, and semicolons
- Comments in C
- Basic program execution

### 2. Input and Output
- Using `printf()` to display output
- Using `scanf()` to take user input
- Format specifiers
- Printing variables and calculated results

### 3. Variables and Data Types
- Variable declaration and initialization
- `int`, `float`, `double`, and `char`
- Constants and basic naming rules
- Understanding values stored in variables

### 4. Operators and Calculations
- Addition, subtraction, multiplication, and division
- Modulus operator
- Operator precedence
- Basic mathematical expressions
- Simple type conversion

### 5. Basic Problem Solving
- Sum and average of numbers
- Area and perimeter calculations
- Temperature conversion
- Simple interest calculation
- Swapping two variables
- Other introductory programming exercises

## How to Compile and Run

Make sure a C compiler, such as GCC, is installed on your system.

### Step 1: Compile

```bash
gcc HelloWorld.c -o HelloWorld
```

### Step 2: Run

On Linux or macOS:

```bash
./HelloWorld
```

On Windows:

```bash
HelloWorld.exe
```

You can also compile and run the programs using Code::Blocks or another C-compatible IDE.

## Example Program

The following example demonstrates the basic structure of a C program.

```c
#include <stdio.h>

int main()
{
    printf("Hello, World!\n");

    return 0;
}
```

### Expected Output

```text
Hello, World!
```

## Recommended Practice Method

For each program:

1. Read the problem statement carefully.
2. Identify the required inputs and expected outputs.
3. Understand the formula or logic before coding.
4. Write the C program independently.
5. Compile and execute the program.
6. Test it with different input values.
7. Review errors and improve your solution.

## Learning Guidelines

- Use meaningful variable names.
- Follow consistent indentation and formatting.
- Add comments when they improve readability.
- Avoid copying code without understanding the logic.
- Test boundary cases whenever applicable.
- Keep each program simple, readable, and focused on one concept.

### Compile a C Program

Navigate to the folder containing the source file and run:

```bash
gcc ProgramName.c -o ProgramName
```

For programs that use functions from `math.h`, you may need to link the math library:

```bash
gcc ProgramName.c -o ProgramName -lm
```

### Execute the Program

**Linux/macOS:**

```bash
./ProgramName
```

**Windows:**

```text
ProgramName.exe
```

Replace `ProgramName` with the actual name of the program you want to execute.

## Learning Approach

This repository follows a structured, practice-oriented learning process.

1. **Understand** — Read the problem statement carefully.
2. **Analyze** — Identify the inputs, expected outputs, and required logic.
3. **Plan** — Develop a step-by-step solving approach.
4. **Implement** — Write the solution using C.
5. **Test** — Verify the program with sample and boundary inputs.
6. **Review** — Improve readability, correctness, and efficiency.
7. **Document** — Record the problem and solution for future revision.

The emphasis is on understanding the logic behind each solution rather than simply memorizing code.

## Coding Principles

The programs in this repository aim to follow these principles:

- **Readability:** Use meaningful variable names and clear formatting.
- **Simplicity:** Prefer beginner-friendly solutions when appropriate.
- **Correctness:** Check the logic and test important input cases.
- **Efficiency:** Avoid unnecessary operations where practical.
- **Documentation:** Explain the approach and important concepts.
- **Consistency:** Follow a uniform naming and folder structure.

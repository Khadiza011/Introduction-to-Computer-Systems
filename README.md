# Introduction to Computer Systems (ICS)

This repository contains all of my Introduction to Computer Systems (ICS) course materials, notes, and practice programs written in C.

## Topics Covered

- Introduction to C Programming
- C Syntax, Data Types, and Variables
- Built-in Functions
- Basic Input and Output (Formatted I/O)
- Arithmetic Operators
- Relational and Logical Operators
- Conditional Statements
- `if`, `if-else`, and `if-else-if`
- Nested `if-else`
- `switch-case` Statements
- Nested `switch-case`
- Loops and Iterative Approaches
- `for` and `while` Loops
- Basic Problem Solving
- Real-Life Problem Solving
- Beecrowd Practice Problems
- Class Tests and Assignments

## Language

- C

## Purpose

This repository is maintained to organize all ICS course materials, practice C programming, improve problem-solving skills, and track my learning progress throughout the course.
